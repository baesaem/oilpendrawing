# 리천 오일펜 드로잉 도우미 (Oil Pen Drawing)

**드로잉 초보자가 촬영한 사진을 보고 스케치북에 오일펜으로 그릴 때 옆에 두는 참고서**입니다.
사진을 격자·윤곽선·명암 단계로 나눠 보여 주고, 브라우저가 사진을 펜 드로잉으로 바꿔 따라 그릴 완성 참고를 만들어 줍니다.
견본 드로잉을 올리면 그 선 굵기·해칭 방향·간격·톤을 읽어 같은 기법으로 그립니다. 모두 브라우저 안에서 계산하며 서버도 API 키도 필요 없습니다.
AI 생성은 선택 기능으로, 사용자가 직접 입력한 API 키(BYOK)가 있을 때만 켜집니다.

## 기능

### 그리기 가이드 (API 비용 없음, 브라우저에서 계산)
1. **구도** — 사진 위에 3×3 / 4×4 / 6×6 격자와 용지 비율(A4 세로·가로, 정방형, 4:5) 틀을 겹쳐 보여 줍니다.
2. **큰 형태** — 사진에서 윤곽선만 추출한 선화. 숙련도가 낮을수록 굵은 윤곽만 남깁니다.
3. **명암** — 사진을 3단계(초급)·4단계(중급)·5단계(상급) 명암으로 단순화합니다.
4. **완성 참고** — AI 드로잉을 격자와 함께 보며 마무리. "과정 그림 만들기"로 4단계를 한 장(2×2)에 그려 받을 수 있습니다.

각 단계마다 오일펜(지울 수 없는 펜)에 맞춘 팁이 숙련도·화풍·빛 방향에 따라 바뀝니다.

**전체화면(F)**: 태블릿을 스케치북 옆에 세워 두고 쓰는 모드입니다. 현재 단계 그림만 크게 보이고 격자는 유지됩니다.
← → 로 단계 이동, G 로 격자 순환, 스페이스로 결과/원본 전환, Esc 로 닫기. 지원되는 브라우저에서는 화면 꺼짐을 막습니다.

### 드로잉 만들기 (기본, API 비용 없음)

- 사진을 톤 단계로 나누고 단계마다 손으로 그은 듯한 해칭을 쌓은 뒤 윤곽선을 얹어 종이 위에 합성합니다. Web Worker 에서 1초 안팎.
- **선·톤 패널**에서 채우기(어반 스케치·한 방향·교차·윤곽·스크리블·점묘), 톤 단계, 여백, 선 굵기, 윤곽선 밀도, 해칭 각도·간격, 손떨림, 가장자리 여백, 종이·잉크색을 조절합니다. 움직이면 결과가 바로 다시 그려집니다.
- **참고 작가 프리셋** 두 가지가 기본으로 들어 있습니다.
  - **리천 스타일** ([@richeons_drawing_journey](https://www.instagram.com/richeons_drawing_journey/), 기본값): 가는 검정 펜, 면의 방향을 따르는 해칭(벽은 세로, 바닥은 원근 방향), 나뭇잎은 고리 선 뭉치, 하늘과 하이라이트는 흰 종이, 가장자리는 미완성으로 흐려짐.
  - **세밀 펜화**: 아주 가는 선으로 종이 끝까지 완성, 수평 하늘 해칭 속 흰 구름, 깊은 그림자는 먹으로, 잔결 질감.
  - "어반 스케치" 채우기는 구조 텐서로 면의 방향장을 구해 그 방향으로 짧은 획을 잇고, 밝기 분산이 큰 잔결 영역(나뭇잎)은 고리 선으로 채웁니다.
- **낙관 2개·사인 3개 등록**: 사진을 올리면 종이 배경을 지워 등록하고(낙관은 글자로 만들 수도, 사인은 직접 그릴 수도 있음), 등록한 것을 눌러 그림에 놓은 뒤 **마우스로 끌어서 위치를 옮깁니다**. 크기는 슬라이더. 저장 PNG에 함께 들어가고, 등록·배치는 이 브라우저에 기억됩니다.
- **견본 드로잉을 올리면 자동 분석**해 위 값을 채웁니다. 종이·잉크색, 톤 단계 수, 여백 비율, 선 굵기(침식 횟수), 해칭 각도(그래디언트 방향 히스토그램), 간격(수직 방향 선 개수), 손떨림(방향 집중도), 채우기 방식을 잽니다. 폰 사진의 조명 얼룩은 큰 블러로 나눠 평탄화합니다.
- 견본 반영도는 숙련도 기본값과 측정값을 섞는 비율입니다. 측정이 어긋나면 슬라이더로 바로 고치면 됩니다.
- **빛의 방향**은 사진을 올리면 명암에서 자동으로 읽어 다이얼에 표시합니다. 다이얼을 돌리면 사진을 그 방향의 빛으로 다시 조명(밝기 기울기)해서 로컬 렌더러와 AI 양쪽에 보냅니다. 편집형 AI와 로컬 렌더러는 글보다 사진의 명암을 따르기 때문에, 사진 자체를 바꿔야 빛 방향이 결과에 반영됩니다. 큰 그림자 방향이 바뀌는 근사이고, 물체 옆면의 세부 명암까지는 옮기지 못합니다.
- **AI에 로컬 결과를 견본으로 보내기** 스위치(기본 켬): 로컬 드로잉이 떠 있으면 그 이미지를 두 번째 이미지로 함께 보내 AI가 해칭 방향과 톤 배치를 정확히 따르게 합니다. 로컬이 구조와 기법을 잡고 AI가 손맛을 다듬는 조합입니다. 반영도는 견본 반영도 슬라이더를 따르고, 이미지 입력이 없는 xAI 에는 적용되지 않습니다.
- 선·톤 패널 값은 AI 지시문에도 문장으로 들어갑니다(채우기 방식, 톤 단계, 여백, 선 굵기, 윤곽선 밀도, 간격, 손떨림, 가장자리 여백). 채우기·톤 단계·여백·굵기는 잘 따르고, 각도·간격은 대략만 따릅니다.

### AI로 그리기 (선택, API 키 필요)

- 원본 사진 업로드 (컬러/흑백 자동 감지, 흑백 변환 옵션)
- 견본 드로잉 업로드 + 반영도 조절 (선택)
- 표현 설정: 화풍(16종, 애니·웹툰·만화·수채 담채 포함), 유명 화가 화풍 접목(10명), 숙련도(초급·중급·상급), 강도, 색 표현(컬러·흑백·세피아), 빛의 방향(8방향), 밝기, 대비
- 원본·결과 분할 비교, 스페이스바 전환, PNG 저장, 최근 30개 이력(브라우저 IndexedDB)
- **해칭 방향 지시**: 사진 위에 선을 그으면 그 근처의 해칭이 그 방향을 따릅니다 (벽은 세로, 바닥은 원근선). 영향 범위 조절, 되돌리기
- **외부 결과 불러오기**: Dynamic Auto-Painter 등 다른 프로그램으로 그린 그림을 넣으면 이 사진의 완성 참고가 됩니다 (`docs/dap-workflow.md`)
- **화풍 프리셋 갤러리**: 같은 사진을 화풍마다 그린 예시 그림을 보고 눌러 고릅니다. AI 로 그릴 때 견본이 없으면 그 예시 그림이 견본으로 함께 갑니다
- **즐겨찾기 프리셋**: 마음에 드는 선·톤을 이름 붙여 저장하고 다음 사진에 바로 적용 (이 브라우저에 저장)
- 제공사: Google Gemini, OpenAI(GPT 이미지), xAI(Grok) — 모델 ID와 기본 URL은 설정에서 변경 가능

## 실행 (Windows, 가장 쉬운 방법)

1. 저장소를 원하는 폴더에 내려받습니다.

   ```bat
   cd /d C:\Users\USER\프로젝트3
   git clone https://github.com/baesaem/oilpendrawing.git
   ```

2. 만들어진 `oilpendrawing` 폴더에서 **`start.bat` 을 더블클릭**합니다.
   처음 한 번은 필요한 파일을 내려받느라 몇 분 걸리고, 그다음부터는 바로 열립니다.
   나중에 최신 버전을 받으려면 `update.bat` 을 더블클릭하세요.

## 작업 흐름 (PC 에서 작업, GitHub 에서 배포)

1. PC 에서 코드를 고친다. `start.bat` 을 켜 두면 저장할 때마다 브라우저가 갱신된다.
2. **`deploy.bat` 을 더블클릭**한다. 바뀐 파일을 보여 주고, 한 줄 설명을 받아 GitHub 으로 보낸다.
3. GitHub Actions 가 자동으로 빌드해 배포한다. 1~2분 뒤 배포 주소에 반영된다.
   진행 상황은 https://github.com/baesaem/oilpendrawing/actions 에서 볼 수 있다.

다른 PC 에서 이어 작업할 때는 `update.bat` 으로 최신 내용을 받는다.

## 개발

```bash
npm install
npm run dev        # 브라우저가 자동으로 http://localhost:5173/ 을 엽니다
npm run build      # 타입 검사 + dist/ 빌드 (GitHub Pages용 /oilpendrawing/ 경로)
VITE_BASE=/ npm run build   # 루트 경로에 배포할 때
```

개발 서버는 5173 포트로 고정되고(다른 프로그램이 쓰고 있으면 오류로 알려 줍니다), 같은 네트워크의 태블릿에서도
터미널에 표시된 `Network:` 주소로 열 수 있습니다. `http://localhost:5173/oilpendrawing/` 로 들어와도 루트로 안내됩니다.

## 배포 (리천 기타교실과 같은 구조)

`main` 또는 작업 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 GitHub Pages로 배포합니다.

배포 주소: **https://baesaem.github.io/oilpendrawing/** (소개 페이지는 `/intro/`)

1. 저장소는 **공개(Public)** 여야 합니다. 무료 계정의 Pages는 공개 저장소에서만 동작합니다.
2. **Settings → Pages → Source**를 "GitHub Actions"로 설정합니다.
3. (선택) 커스텀 도메인: **Settings → Secrets and variables → Actions → Variables**에 `PAGES_DOMAIN` = `oilpen.richeon.kr` 처럼 넣고,
   DNS에 `oilpen` CNAME → `baesaem.github.io` 레코드를 추가합니다. 변수가 비어 있으면 https://baesaem.github.io/oilpendrawing/ 에 배포됩니다.

소개 페이지는 `/intro/` 에 있습니다 (`public/intro/index.html`).

## 화가 화풍 접목

반 고흐, 렘브란트, 다 빈치, 뒤러, 실레, 호쿠사이, 마티스, 콜비츠, 모란디, 자코메티의 **드로잉 기법**을 접목할 수 있습니다.
모두 사후 60년 이상 지난 작가(저작권 만료)로만 구성했으며, 지시문에는 이름과 함께 선·명암 기법을 풀어 써서
모델이 이름 사용을 피하더라도 특징이 유지되게 했습니다. 가이드 모드의 팁에도 그 화가처럼 손으로 그리는 요령이 추가됩니다.
목록은 `src/artists.ts`에서 수정합니다.

## 제공사 메모

| 제공사 | 방식 | 기본 모델 ID |
|---|---|---|
| Google Gemini | `generateContent`에 사진(+견본)을 inline 이미지로 첨부해 편집 | `gemini-2.5-flash-image` |
| OpenAI | `POST /v1/images/edits` 멀티파트, `image[]`에 사진(+견본) | `gpt-image-1` |
| xAI | 사진을 비전 모델로 묘사 → `POST /v1/images/generations`로 새로 그림 | `grok-2-image` (비전: `grok-4`) |

xAI는 입력 이미지를 직접 편집하는 API가 없어 2단계로 동작하며 원본 구도 재현 정확도가 낮습니다.
모델 ID는 제공사가 바꿀 수 있으므로 오류가 나면 **API 키 설정 → 고급**에서 최신 ID로 바꾸세요.
브라우저 직접 호출(CORS)을 막는 제공사가 있으면 같은 곳에서 기본 URL을 CORS 프록시 주소로 바꿉니다.
