# Dynamic Auto-Painter 와 함께 쓰기

이 앱은 브라우저에서 돌아가는 웹 앱이라 PC 에 설치된 Dynamic Auto-Painter(DAP)를 직접 실행하거나 결과를 가져올 수 없습니다.
브라우저는 보안상 PC 의 프로그램을 부를 수 없기 때문입니다. 대신 **DAP 로 그린 그림을 앱에 불러오는** 방식으로 함께 씁니다.

## 흐름

1. 앱에 사진을 올리고 **그리기 가이드**(구도 → 큰 형태 → 명암)로 스케치북에 밑그림을 잡습니다. 이 단계는 DAP 와 무관합니다.
2. 같은 사진을 DAP 에서 열어 펜·잉크 계열 프리셋으로 그립니다. 결과를 PNG 나 JPG 로 저장합니다.
   - 사진과 **같은 가로세로 비율**로 저장하세요 (자르지 않기). 비율이 다르면 앱의 원본·결과 비교가 어긋납니다.
   - 긴 변 1500~2500px 이면 충분합니다. 앱이 2048px 로 줄입니다.
3. 앱의 왼쪽 패널 **외부 결과** 칸에 그 파일을 넣습니다. 그 그림이 이 사진의 완성 참고가 되어
   원본·결과 비교, 격자, 전체화면, 낙관·사인, PNG 저장이 그대로 됩니다.
4. 원하면 "AI 키"를 연결하고 **AI로 그리기**를 누릅니다. 입력 패널의 스위치가 켜져 있으면 DAP 결과가 AI 에 견본으로 함께
   보내져, 그 톤 배치와 질감을 따르되 손으로 그은 펜 선으로 다시 그립니다.

## 자동화에 대해

DAP 가 명령줄 실행이나 감시 폴더(파일을 넣으면 자동 처리) 같은 **외부 실행 수단**을 제공한다면, PC 에 작은 중계 프로그램을 두어
앱의 "드로잉 만들기" 버튼이 DAP 를 부르게 만들 수 있습니다. 그 경우에도 웹 앱은 그 중계 프로그램(PC 의 localhost)과만 통신합니다.
DAP 7 의 도움말이나 매뉴얼에서 command line / batch / watch folder 항목이 있는지 확인해 주세요. 없으면 위의 불러오기 방식이 유일합니다.

## 로컬 렌더러의 위치

앱 안의 로컬 렌더러는 키·비용·인터넷 없이 태블릿에서도 즉시 도는 것이 장점이지만, 나무·풀처럼 잔결이 많은 풍경에서는
AI 나 DAP 보다 품질이 크게 떨어집니다. 건물·실내·정물처럼 면이 뚜렷한 사진에 맞습니다.
